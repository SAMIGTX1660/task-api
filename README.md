# Task API

A small Express task API with interactive OpenAPI documentation.

## Run locally

```sh
npm start
```

Open [http://localhost:3000/docs](http://localhost:3000/docs) to explore the API. In Swagger UI, use **Try it out** to create a task, list tasks, update the created task, and delete it.

The API starts with three sample tasks. Data is held in memory and resets when the server restarts.
